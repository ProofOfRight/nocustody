# 0017. Documentation language

- Status: accepted, amended by [0020](0020-internal-docs-outside-repo.md)
- Date: 2026-10-26

## Context

Public contributors are international; the owner's working language is Russian.

## Decision

English for everything external readers use: README, SECURITY, CONTRIBUTING, threat model, ADRs, code comments. Working documents (project brief, roadmap, open questions, design notes) stay in Russian for now.

## Consequences

Russian design notes may be translated later together with zh/ru README.
