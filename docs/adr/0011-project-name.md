# 0011. Project name `nocustody`, separate GitHub organization

- Status: hosting part superseded by [0032](0032-repository-hosting.md); the name still accepted
- Date: 2026-10-26

## Context

The project must be independent from the first consumer's brand. On 2026-10-26 `nocustody` was free on npm (`npm view`) and as a GitHub login (`gh api users/…` → 404). Trademark search was not performed.

## Decision

Name the project `nocustody`; host it under a separate GitHub organization.

## Consequences

Package name `nocustody`. The organization has to be created by the owner.
